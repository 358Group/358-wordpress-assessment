About

A directory that feels like a notebook

Fewer apps. Honest blurbs. No app-store fireworks.

App Lane is the directory half of this WordPress project. Catalogue structure nods to sites like All Diwa Game; the paper background, leaf accents, and margin-note voice are ours.

Someone on the desk opens an app, uses it for a day, then writes a short paragraph. If we cannot say something specific, it does not make the shelf.

Who this is for

Managers reviewing a complete WordPress directory theme — home catalogue, app detail pages, about, contact, legal, and sitemap — not an empty default blog.
